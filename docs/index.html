よくある質問

海上釣り堀用のエサには何がありますか？

ダンゴ・練り餌、オキアミ、魚の切り身、エビなどを取り扱っています。生ミック・マダイイエローのほか、魚かし・練餌海道・本多商店などの商品も掲載しています。価格や在庫を比べながらお選びください。

ダンゴの一覧へ

活き餌やサビキ釣りのエサも買えますか？

活き餌はギンペイ・モエビ、サビキ用エサはアミ姫・サビキ三昧などを掲載しています。入荷や販売状況で在庫は変わります。
